# 🎮 Global Video Game Sales Analytics: Power BI Dashboard

**Microsoft Elevate AICTE Internship - Capstone Project** **Author:** Vedant

## 📌 Project Overview
This repository contains a comprehensive, interactive Business Intelligence dashboard built using **Microsoft Power BI**. The project analyzes historical video game sales data (over 16,500 individual game records) to uncover global market trends, regional cultural divides in consumer preferences, and the strategic efficiency of top game publishers.

Instead of static reporting, this dashboard is designed with an "app-like" user experience, utilizing custom DAX measures, dynamic filtering, and advanced visual storytelling.

## 📊 Dashboard Features
The Power BI report (`.pbix`) is segmented into three highly interactive pages:

1. **Executive Summary**
   * High-level Key Performance Indicators (KPIs) tracking total global revenue and volume.
   * Macro-level time-series analysis showing industry booms and dips over decades.
   * Pareto Analysis demonstrating the "80/20 rule" of hit-driven revenue in the gaming industry.

2. **Market & Publisher Analysis**
   * Granular breakdown of the "Console Wars" and platform market share.
   * Custom publisher efficiency analysis (Quality vs. Quantity strategy).
   * DAX-driven segmentation bucketing games into performance tiers (Blockbusters, Mega Hits, Standard Hits).

3. **Regional Cultural Divide & Game Explorer**
   * Scatter and correlation plots proving the stark contrast between North American (Shooter/Action) and Japanese (Role-Playing) gaming tastes.
   * An interactive "Game Explorer" utilizing a custom text-search visual and gauge benchmarks to instantly pull up the "Sales DNA" of any specific game in the database.

## 🛠️ Technical Stack & Skills Demonstrated
* **Tool:** Microsoft Power BI Desktop
* **Data Preprocessing (Power Query):** Handled missing values, standardized data types across legacy records, and optimized the data model for performance.
* **Feature Engineering (DAX):** Wrote custom Data Analysis Expressions (DAX) to create dynamic aggregations, cumulative totals, and categorical logic gates.
* **UI/UX Design:** Implemented page navigation, custom tooltips, minimal data-ink ratios, and a cohesive dark-themed aesthetic.

## 📂 Dataset
The dataset (`vgsales.csv`) used for this project was generated by a scrape of vgchartz.com.
* **Records:** 16,598 rows
* **Features:** Rank, Name, Platform, Year, Genre, Publisher, NA_Sales, EU_Sales, JP_Sales, Other_Sales, Global_Sales (in millions).

## 🚀 How to Run the Project
1. Download the `vgsales_dashboard.pbix` file from this repository.
2. Open the file using **Microsoft Power BI Desktop**.
3. Use the left-hand navigation buttons to explore the different pages. 
4. Interact with the dropdown slicers, timeline sliders, and charts to dynamically filter the data.
